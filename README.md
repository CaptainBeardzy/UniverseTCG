UniverseTCG is a random event generator that is intended to be used alongside a wrestling 'universe mode' such as the WWE 2K universe modes.
It is designed to act a bit like a Chaos wheel, for selecting events, but with a bit more structure.

This primary branch is the working branch, as I am working on this intermitently across multiple devices and testing entirely within GitHub Pages.
With that in mind, this branch is not necessarily the most stable branch, the current stable version is listed as SingleIndex_a2STAR, which was branched on 09/04/2026.

At the beginning of a show you will have the opportunity to open a booster pack, which will contain three cards. Each pack currently contains exactly 1 card from each of the below categories, which will be explained in more detail.

The cards in the initial 'core' pack are split into 3 categories.
1. Face
2. Promo
3. Heel

**Face Cards**
Face Cards are designed to be 'positive' events. This includes things like using special match types, pushes for lowercard stars, and transfers between brands.
Using the Face Cards is 'optional', and costs resources that can be earned each show through 'promo' cards.

**Promo Cards**
The Promo cards, as mentioned above, are resource cards that contain the components you need for using the **Face** cards. As of 09/04/2026 these resources have been in no way balanced, and I suspect that it's unlikely that you'll be in a position where you don't have enough of a given resources to use any of the face cards. Currently there are three resources: Heat, Hype, and Clout. Throughout the process of putting the cards together these may be used more-or-less, with Clout being the one currently not being utilised very much during testing. Promo cards must be played as soon as you receive them, using the 'cash in' button when you draw the cards. The resources will be automatically added to your totals.

**Heel Cards**
Heel cards are the real 'chaos' cards, and the core loop of this 'game'. These are designed to be impactful events, such as injuries, lost luggage, etc.
They are completely free to play (don't cost resources) but are also mandatory. If you have a Heel card in your hand that is due to be played, then you won't be able to continue to the next week until you've played the card.

**Some random features and notes**
1. Cards can be played from the Hands Screen
2. Cards have a duration (for example injuries), and will stay within the 'active' page until this duration expires, once they have been played.
3. Cards also have a limited window they can be played in;
     - For Face cards: The card will automatically be discarded once the window expires, if the card has not been played.
     - For Heel Cards: Once the card reaches 'immediate' in the play window, you won't be able to move to the next week until you've played it. If the card has         a longer window still available, you can wait to play it in the future, as long as it is still within that window.
     - Promo Cards: as mentioned above, are instant play cards every draw, so don't have an active timer as such.
